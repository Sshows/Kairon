## Уточнения к историческим примерам

- Книга по malware показывает Windows/VMware 2012 года. NAT не означает
  отсутствие интернета, Host-only не исключает связи с хостом, снимок не
  отменяет внешних действий. Используются собственные безвредные данные.
- Упоминания MD5/SHA-1 в старой идентификации образцов не превращены в
  рекомендации для новых механизмов целостности: здесь SHA-256.
- Для IDOR статус 200 отделён от выдачи чужих приватных данных. UUID не
  заменяет проверку прав; учитывается модель приватного/общего доступа.
- HMAC отделён от шифрования и защиты от повторов. AEAD выполняет библиотека
  cryptography; неверная метка не допускает принятия текста. Nonce при
  шифровании в опыте не повторяется. TLS включает отдельные задачи
  идентификации, обмена ключами и защиты записей.
- CPython не обещает одинаковый байткод между версиями. Путь проверяется
  после нормализации как потомок папки, с оговоркой о гонках файловой системы.

Первичные справки: [Python ast](https://docs.python.org/3/library/ast.html),
[Python dis](https://docs.python.org/3/library/dis.html),
[AESGCM](https://cryptography.io/en/latest/hazmat/primitives/aead/),
[RFC 8446](https://www.rfc-editor.org/rfc/rfc8446.html).

## Реализация и проверки

src/lib/book-courses.ts имеет server-only и выбирает Markdown только из
каталога. Все новые страницы и динамическая metadata вызывают requireUser.
Markdown рендерится сервером с отключённым сырым HTML. Самопроверка не требует
клиентского набора данных или API. Tracing включает Markdown собственных
занятий. Сборка ищет контрольные тексты в публичных JS-файлах.

Шесть Python-проверок исполняют видимые программы из Markdown на временных
данных: отчёт/плохой JSON, матрица прав, HMAC/три подмены AEAD, реальный
файловый результат процесса, AST/байткод/путь, loopback HTTP 200/404/отказ.
Криптобиблиотека устанавливается в CI из системного пакета Ubuntu.
Vitest проверяет источники, подготовительные ссылки и недопустимый путь.
Браузер проверяет все новые страницы, навигацию, мобильную ширину, раскрытие
ответа и запрет анонимного доступа.
