# Статус проверки Kairon 0.2

Проверено 25 октября 2026 года. [Старт с нуля](https://kairon-phi.vercel.app/paths/from-zero), [первый урок](https://kairon-phi.vercel.app/learn/permission), [терминал](https://kairon-phi.vercel.app/terminal).

## Первый учебный релиз

- 10 русских уроков опубликованы, максимальная награда 830 XP.
- Практика в браузерной симуляции и в своей Kali. Внешняя Kali не подключается к сайту; в этом режиме проверяется ответ ученика.
- Миграция LessonProgress сначала применена к development, там прошли RLS-проверки. Затем та же миграция применена к production без удаления существующих данных.
- Unit: 7 тестов успешно. Проверены пароли, пути, кавычки, grep, запись файлов, права, границы симуляции и все авторские решения.
- GitHub CI [40124326692](https://github.com/Sshows/Kairon/actions/runs/40124326692) для f329009 — PASS: lint, TypeScript, unit, миграции, RLS, production build и 4 браузерных теста.
- Браузерные тесты включают терминал, сброс, закрытый разбор, режим своей Kali, порядок уроков, подсказку, 4 одновременных отправки без удвоения XP, USER/ADMIN и блокировку.
- Публичные скриншоты desktop 1440px и mobile 390px получены из CI и просмотрены. Горизонтальное переполнение на mobile отсутствует. Найден слабый контраст кнопки-ссылки; добавлен явный цвет для default Button.
- Локальная сборка Webpack — PASS. Локальный Turbopack на Windows не смог запустить процесс CSS. Linux CI и Vercel собрали приложение обычной production-командой Turbopack успешно.

## Проверка рабочего сайта

Production deployment dpl_AGtZgbktyZjyC2U4XaToxWoVfxnT: READY, постоянный адрес https://kairon-phi.vercel.app. Публичные страницы отвечают без авторизации Vercel.

Проверены запрет пропуска, серверное повторение команд, неуспех подделанного ответа, скидка за подсказку, режим своей Kali, открытие разбора, профиль и повтор последнего задания. 20 параллельных GET к трём публичным страницам: 20 HTTP 200, медиана 1241 мс, p95 1460 мс, максимум 1469 мс с точки выполнения агента. Это небольшой smoke-тест, а не определение предела нагрузки. Он не моделирует множество вошедших учеников и длительные серверные Kali-сессии. Нельзя обещать конкретную вместимость бесплатного тарифа по этому результату.

## Инфраструктура и оставшиеся границы

Vercel Hobby, Neon Free (main/development, 0.25 CU, Frankfurt), без платных услуг и новых серверов. Тренажёр исполняет команды в браузере, сервер принимает только проверки/подсказки и сохраняет прогресс. Настоящие удалённые Kali-контейнеры, WebSocket и Ollama не запущены.

Код в GitHub синхронизирован. Автодеплой не активирован: GitHub API пока не видит VERCEL_TOKEN, DEPLOY_ENABLED=false. Публикация этого релиза выполняется авторизованным CLI. Это не мешает работе текущей ссылки, но один push сам по себе пока не обновит сайт.

Редактор контента в админке, полноценные БД Path/Module/Lesson, лидерборд, сертификаты, остальные учебные пути и MCP самой платформы остаются дальнейшей работой. Установленные Neon skills/MCP — инструмент разработки, отдельный от будущего MCP Kairon.
