# Статус проверки Kairon 0.4

27 октября 2026 года. Новый путь «Безопасность в компании»: 12 уроков, 1360 XP, три модуля и 27 файлов. Вместе с Kali — 32 урока, максимальная награда 3490 XP. Релиз опубликован после локальных проверок, CI и просмотра скриншотов; рабочий HTTPS дополнительно проверен после переключения адреса.

## Подтверждено локально

- 7 unit-тестов: пароли, оба курса, приватный DTO, ответы, независимый порядок и охват аудита источника.
- 6 тестов нового набора: ZIP/manifest, события и заявки, контекст приоритета, демо-секреты/доступы, SSH/IDOR, восстановление отдельной временной копии.
- Структура контента: 12 новых уроков, три модуля по четыре, три подсказки и чек-листа у каждого.
- Миграций БД нет; старый прогресс и Kali сохраняются.
- ESLint, TypeScript и production-сборка Webpack прошли. Прежние 5 Python-проверок набора Kali тоже прошли.

Повторная проверка публичного HTTPS подтвердила:

- Оба пути, первый урок компании и разбор источника открываются без авторизации Vercel; правильные ответы не вложены в HTML.
- Оба ZIP совпадают с manifest. SHA256 набора компании — 4dd9eddbf90647772730fcdbf73a8f0598c1ca95de940ef35f1c094d11490516; набор Kali не изменён.
- Все 32 гостевых ответа проходят с guest=true, xp=0 и разбором.
- Одноразовый USER начал путь компании до Kali: порядок проверяется внутри своего пути, четыре одновременных первых ответа не дублируют XP. Завершённый путь компании не завершает Kali в профиле.
- Затем тот же USER завершил оба пути: ровно 32 строки прогресса, 3460 XP с тремя использованными подсказками; повторный ответ возвращает already=true. Профиль показывает завершение обоих путей.
- Тестовый аккаунт и его данные удалены по собственному UUID; отсутствие аккаунта после удаления проверено. Реальные пользователи не менялись.

Исходники отправлены в Sshows/Kairon; релиз опубликован авторизованным Vercel CLI. GitHub Actions deploy пропущен существующим условием DEPLOY_ENABLED: автоматическую публикацию этим запуском не подтверждаем. Новых платных ресурсов, серверов и миграций production-БД нет.
