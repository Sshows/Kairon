# Статус проверки Kairon 0.3

25 октября 2026 года. Новый курс: 20 гайдов по Kali, практика на компьютере ученика, открытая самопроверка, ZIP с 21 учебным файлом. Старый терминал удалён, его URL перенаправляет на установку.

## Локально подтверждено

- TypeScript и ESLint — PASS.
- Unit: 6 тестов (пароли, структура 20 уроков, ответы, приватный DTO, порядок нового курса) — PASS.
- 5 Python-проверок настоящего набора — PASS: ZIP/manifest/байты всех файлов, фактические улики, PCAP с валидными IP/TCP checksums и HTTP, loopback-сервер/запрет выдачи файлов, запуск/остановка безвредного процесса.
- Next production build через Webpack — PASS.
- Схема PostgreSQL не менялась; данные и ранее заработанные XP не удаляются.

## Проверка перед публикацией

Обновлённый CI запускает lint, typecheck, unit, Python, миграции на временной PostgreSQL 17, реальные RLS-проверки, build и браузерные E2E. Тесты проверяют все 20 ответов в аккаунте, 3 уровня подсказок, конкуренцию без повторного XP, сохранение истории старого курса, права USER/ADMIN и блокировку. Публичный сценарий: гайд → гостевой ответ/подсказка → разбор → следующий урок; ZIP, ссылки, мобильный layout и отсутствие shell.

Результат нового CI, просмотр скриншотов и свежий production deployment будут зафиксированы после выполнения. До этого прежний production 0.2 не является доказательством работоспособности нового курса.

## Пределы проверки

В этой сессии Kali VM, Tor, ClamAV и Wireshark на машине пользователя не устанавливались. Их шаги сверены с официальными источниками. Учебные собственные Python-программы и артефакты проверены отдельно. Самопроверка сайта не доказывает выполнение локальных действий и не оценивает отчёты ученика.

Большая нагрузка нового курса не измерена. Никаких платных ресурсов, VPS или Render для него не подключали.
