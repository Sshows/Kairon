# Курс Kali Linux: версия 0.3

25 октября 2026 года. По новой задаче пользователя обучение перенесено в собственную Kali ученика. Браузерный терминал удалён целиком: компонент, интерпретатор, тесты симулятора, CSS и setup-скрипт. Его URL оставлен только как редирект, чтобы не ломать старые закладки.

## Программа

20 авторских уроков, четыре уровня, максимум 2130 XP:

1. Готовая Kali в VirtualBox, первый вход, снимок, браузеры, Tor, распаковка учебного набора.
2. Подозрительный файл, SHA256 и подмена реквизитов, письмо, журнал входа, права файла.
3. Собственный HTTP-сайт, проверка одного локального порта Nmap, журналы 200/404, готовый искусственный PCAP в Wireshark.
4. Опознание/остановка своей программы, безопасный тест EICAR, восстановление документа, отчёт и финальное дело.

У каждого урока есть объяснение через знакомую аналогию, конкретные шаги, ожидаемый результат, помощь при частой ошибке, чек-лист, вопрос, три подсказки и разбор. Время — редакционная оценка, не измерение учащихся.

## Подготовка

Основной маршрут: Windows Intel/AMD → VirtualBox → официальный готовый образ Kali → распаковка .7z → .vbox рядом с .vdi → Start → kali/kali → свой пароль. Для VMware дана отдельная официальная ссылка, для Apple Silicon — UTM. Цвет значка не используется как признак файла. Схема двух файлов помечена как схема, а не скриншот.

Firefox уже подходит. Chromium устанавливается по желанию из пакетов Kali. Tor Browser скачивается с torproject.org; объяснено, что он не маршрутизирует все программы системы.

## Что проверяет сайт

Гостю доступны самопроверка и подсказки без аккаунта. Результат гостя не сохраняется после обновления. В аккаунте — существующие согласие, порядок, атомарные XP, лимиты и FORCE RLS. Сайт сравнивает ответ, не наблюдает за компьютером и не оценивает содержимое отчёта. Чек-лист нужен самому ученику.

ID уроков новые. История старого курса сохранена в БД и общем XP, исключена из знаменателя нового курса. Никакой массовой переписи прогресса нет.

## Учебный набор

21 файл в ZIP: синтетические логи, письмо, документы/копии, шаблон отчёта, README/код готовности, локальный сервер, безвредный процесс и искусственный PCAP. В наборе нет malware, EICAR, автоустановки или автозапуска. EICAR берётся только самим учеником с официального сайта в отдельном уроке; блокировка загрузки защитой не требует её отключения.

Сервер привязан к 127.0.0.1:8000, не раздаёт каталог и не выполняет команды по HTTP. Для упражнений не нужны VPS, Docker, Render, платная подписка или передача файлов пользователя на платформу.

## Проверки и пределы

Действительные результаты релиза записываются в verification.md. Автоматические проверки набора выполняют собственные программы, сверяют содержимое архива и TCP/IP/HTTP в PCAP. Они не подтверждают, что GUI VirtualBox, Tor, ClamAV или Wireshark уже запущены на компьютере пользователя. Эти маршруты сверены с источниками; живую VM в этой сессии не устанавливали.

Новая схема снижает потребность в серверных вычислениях: тяжёлые инструменты работают у ученика. Вместимость бесплатного веб-хостинга не измерена для большой аудитории.
