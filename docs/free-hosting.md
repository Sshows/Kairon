# Бесплатный запуск

Требование пользователя: без платных ресурсов и подписок. На 24 октября 2026 года подтверждены Vercel Hobby и Neon Free. Сайт: https://kairon-phi.vercel.app.

| Компонент            | Состояние                                          | Ограничения                                                                                      |
| -------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| GitHub Sshows/Kairon | Код опубликован, CI проходит                       | Публичный репозиторий; production-секреты в код не включаются                                    |
| Vercel shows1/kairon | Hobby, production READY, базовая build machine     | Hobby предназначен для личного некоммерческого использования, ограничивает ресурсы               |
| Neon Kairon          | Free, main/development, compute 0.25 CU, Frankfurt | На проверенной странице Free: 100 CU-часов и 1 GB на проект; фактический лимит нужно отслеживать |
| VPS / Kali / Ollama  | Не создавались                                     | Бесплатный постоянный изолированный хост лабораторий пока не подтверждён                         |

Ни платные планы, ни домен, ни облачный AI Gateway не подключались. Для первого сайта используется бесплатный vercel.app-поддомен. Сайт/API на Vercel не заменяют VPS для персональных Kali-сессий.

Render Free не используется: он засыпает после 15 минут без запросов, не предоставляет постоянный диск, его Free PostgreSQL истекает через 30 дней. Это не подходящая замена выбранной долговременной базе и лабораторному хосту.

## Автоматические обновления

В .github/workflows/ci.yml настроен deploy job после успешного verify. Он работает только для main, исключает pull_request, использует Node 24 и зафиксированный Vercel CLI 65.2.0. Секрет VERCEL_TOKEN доступен только production deployment steps. VERCEL_ORG_ID и VERCEL_PROJECT_ID настроены как repository variables. Для включения используется DEPLOY_ENABLED=true.

Прямая Git-интеграция Vercel продолжила отвечать “You need to add a Login Connection” после авторизации. CLI умеет публиковать сайт, но не может сам создать токен: “Cannot create tokens for this app”. Поэтому пользователь создаёт Vercel token и сохраняет его прямо в GitHub Secret VERCEL_TOKEN. Значение в чат не передаётся и не читается обратно. Агент проверяет только metadata наличия, включает DEPLOY_ENABLED и проверяет первый автоматический релиз.

Пока секрет не подтверждён API, DEPLOY_ENABLED остаётся false, а тесты выполняются. Точное текущее состояние — в verification.md. Токен нужно ограничить проектом Kairon, если интерфейс позволяет; иначе командой shows. При ротации меняется только соответствующий GitHub Secret.

Официальные источники: [Vercel Hobby](https://vercel.com/docs/plans/hobby), [Neon pricing](https://neon.com/pricing), [Render Free](https://render.com/docs/free).
