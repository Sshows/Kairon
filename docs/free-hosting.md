# Бесплатный запуск: выбранная схема

Требование пользователя: без платных ресурсов, подписок, пробных кредитов с обязательной оплатой и автоматических переходов на платный план. Проверено по официальным страницам 24 октября 2026 года. Лимиты могут меняться; перед созданием проверяется фактически выбранный план.

| Компонент          | Выбор                          | Ограничение                                                                                                                                              |
| ------------------ | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Исходники и CI     | Публичный GitHub Sshows/Kairon | CI выполняется на временной PostgreSQL и не получает секреты production                                                                                  |
| Сайт и Next.js API | Vercel Hobby                   | Бесплатен для личного некоммерческого использования; есть лимиты ресурсов. Не рассчитан на постоянные Kali-сессии                                        |
| PostgreSQL         | Существующий Neon, только Free | Free без карты и срока окончания; текущая страница указывает 100 CU-часов и 1 GB хранения на проект в месяц. Нужно подтвердить фактический тариф проекта |
| Kali, цели, Ollama | Отдельный сервер ещё не выбран | Бесплатное постоянное размещение с требуемой изоляцией пока не подтверждено. На Этапе 0 не создаётся                                                     |

Render Free — допустимый вариант для некоторых небольших веб-сервисов, но не замена выделенному лабораторному хосту. Free web service засыпает после 15 минут без запросов, не имеет постоянного диска; Free PostgreSQL истекает через 30 дней. Поэтому для данных Kairon выбран Neon. Платные функции Render/Vercel/Neon и покупка домена не заказываются. Для первой ссылки достаточно бесплатного поддомена хостинга.

## Автоматические обновления

Цель: push в main → GitHub CI → Git-интеграция Vercel → актуальный HTTPS-сайт. Связь GitHub–Vercel ещё требуется создать после авторизации. CI уже проверяет build, lint, TypeScript, пароли, PostgreSQL/RLS и реальный вход USER/ADMIN. Защита релиза результатом CI требует отдельной настройки checks/branch rules; наличие workflow само по себе не блокирует автодеплой неуспешного commit.

## Почему пока нет live URL

Код опубликован, CI успешно прошёл. Авторизация Vercel через одноразовые ссылки дважды сразу показала expired; выполняется переход на официальный CLI/device login. В Neon выполнен вход пользователя на сайте, но подключение аккаунта к агенту ещё не подтверждено. Вход в браузере и доступ через интеграцию — разные состояния. До фактического READY и HTTP-проверки ссылка не объявляется работающей.

Официальные источники: [Vercel Hobby](https://vercel.com/docs/plans/hobby), [Neon pricing](https://neon.com/pricing), [Render Free](https://render.com/docs/free).
