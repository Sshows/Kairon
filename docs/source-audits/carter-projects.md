Дата проверки: 28 октября 2026 года. Источник — [CarterPerez-dev/Cybersecurity-Projects](https://github.com/CarterPerez-dev/Cybersecurity-Projects), зафиксированный commit **6a9989cd4858d4c51f0922debcba53668121bea1**.

## Что действительно найдено

В главном README этой версии таблицы содержат **69 отдельных проектов**: три Foundations, 21 Beginner, 23 Intermediate и 22 Advanced. Значок и описание репозитория говорят о 70; дополнительный семидесятый проект для каталога не придумывался. Все 69 строк включены в content/project-catalog.json в исходном порядке.

Для **43** строк найдены соответствующие каталоги PROJECTS. Для **26** опубликован только synopsis с идеей и планом. Наличие каталога обозначено source, наличие одного плана — idea. Это состояние исходного репозитория, а не признак запуска программы в Kairon.

У **41** записи найдена указанная в таблице папка learn. У chaos-engineering-tool ссылка learn присутствует в README, но такой папки в этой версии нет; ложная ссылка в каталог не перенесена. У haskell-reverse-proxy таблица не указывает learn. У 39 из 43 каталогов механически обнаружены файлы, названные как тесты, или файлы в test/tests; это проверка наличия, а не прохождения тестов.

В каталоге также даны ссылки на **10** направлений работы из ROADMAPS/README.md и **5** групп ресурсов из RESOURCES/README.md. Длительность карьеры, текущие цены экзаменов, доступность бесплатных тарифов и рекламные обещания не переносились как проверенные факты. Для занятий Kairon сертификат не требуется.

## Что написано для сайта

Русские названия, объяснение «что это», польза, необходимые понятия, четыре шага самостоятельного разбора и ожидаемый результат написаны для Kairon. Они описывают учебный план, а не выполненный запуск. Каталог помогает выбрать тему; отдельные работающие уроки Kairon отмечаются отдельно в интерфейсе.

Оригинальные исходники и тексты документации не копировались в каталог и не переводились целиком. Ссылки ведут к автору. Пример Simple Port Scanner в исходном README отдельно приписан [@deniskhud](https://github.com/deniskhud); это сохранено в сведениях об источнике.

## Лицензия и границы переноса

Корневой LICENSE содержит GNU Affero General Public License Version 3, README указывает AGPL 3.0. В каталоге сохранены название лицензии и ссылка на её файл. Публикация указателя не является заявлением о лицензировании всех сторонних библиотек и материалов репозитория. Перед отдельным переносом программы нужно отдельно проверить её файлы и зависимости.

Каталог не устанавливает на сайт кейлоггеры, трояны, управляющие агенты, скрытые сетевые каналы, средства обхода антивируса и сборщики настоящих ключей. Для таких тем дан защитный разбор на вымышленных записях и схема понимания риска. Проверки доступны только для своей лаборатории или согласованной цели; реальные личные данные и рабочие секреты не нужны.

Советы из источника не выдаются за гарантии. В частности: вид хеша не доказывает его алгоритм; Base64 не является шифрованием; открытый порт не является доказательством уязвимости; HTTP-код без содержимого не доказывает нарушение доступа; совпадение с правилом не доказывает вредоносность; отсутствие находок не доказывает безопасность; программный эмулятор не обладает физическими гарантиями HSM. Код 420 из проекта ограничителя запросов не назван общим стандартом HTTP. Заявленные скорость, точность и полнота исходных инструментов нами не измерялись.
