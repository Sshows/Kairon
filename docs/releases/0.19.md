# 0.19 — понятные действия перед подробным объяснением

Ученица второго дня смогла выполнить задания после отдельных пошаговых подсказок, но не смогла самостоятельно выделить их из старого текста. Изменение устраняет эту проблему на уровне страниц и учебных материалов.

## Что изменилось

- Все 129 уроков получили явно названные обязательные разделы «Сделай сейчас» и карточку цели. В 102 уроках отдельная подробная теория раскрывается через «Почему это работает»; необходимые условия, результаты и устранение ошибок остаются видимыми.
- В 20 уроках Kali, 12 уроках основ и 24 уроках инструментов переработаны последовательности действий: конкретное место работы, шаг, ожидаемый результат и объяснение назначения. В остальных 73 уроках упорядочены разделы и сохранена содержательная основа.
- Во втором дне: файловый менеджер → Videos/Видео или другая существующая папка → пустое место → Open Terminal Here → pwd. Добавлена подписанная схема, а не выданный за настоящий снимок интерфейса рисунок.
- Смена пароля разбита на пять запросов и результатов. Невидимый ввод отмечен заметным предупреждением. Учтены другой язык интерфейса, своё имя пользователя и уже установленный личный пароль.
- Убраны повторные приложения с отсутствующими файлами, противоречивыми выводами, готовыми ответами и неподтверждёнными историями/CVE. Содержательные исходные разборы сохранены.
- Общая подготовка практики в новых книжных занятиях тоже разделена на действия и результаты. Источники Markdown и сгенерированный JSON синхронизированы.

## Данные и безопасность

Остались 76 дней и 129 прежних идентификаторов уроков. Сравнение всех записей с предыдущим коммитом подтвердило неизменность ID, вопросов, ответов, вариантов, XP и признаков набора. У первого запуска уточнены описание, цель и личный контрольный список. Схема PostgreSQL и миграции в этой версии не меняются.

Доступ по проверенной сессии и разделение данных аккаунтов сохраняются. Схема для первого запуска передаётся с сервера после проверки доступа. Проверка публичных клиентских файлов проходит: 26 файлов и 364 фрагмента учебного текста; общедоступный индекс содержит только ID.

## Проверка

Локально прошли сборка, lint, 49 Vitest-проверок и 16 исполняемых книжных примеров Python. В GitHub Actions запускаются PostgreSQL, проверки аккаунтов, настоящие Linux-инструменты и браузерные сценарии.

Два прежних предположения браузерных тестов обновлены под новые заголовки и регистр предупреждения. Ещё одна проверка раньше читала базу сразу после появления «Самопроверка пройдена», до завершения запроса сохранения; теперь она ждёт отдельного подтверждения «Отметка сохранена в аккаунте». Проверка сохранения по-прежнему обязательна.

Локальный Docker не запустился из-за прежнего зависшего sailor-ingest.sock. Автоматическая проверка отклонила остановку процессов и удаление сокета; локальные контейнеры не использовались. Изолированные проверки базы и Linux выполнены в CI.

Итоговый [GitHub Actions run 41493889353](https://github.com/Sshows/Kairon/actions/runs/41493889353) завершён успешно: verify и juice-shop — success, в том числе 49 Vitest и 16 Playwright-сценариев. Автоматический deploy по существующему условию DEPLOY_ENABLED пропущен; публикация выполнена через CLI.
