# Редактура объяснений — 0.13

Проверены структура и объём 106 уроков. Основной недостаток был в 38 коротких
уроках: 14 первых практических дел, 8 занятий по диагностике, 8 по анализу файлов
и 8 по Python. Между терминами, действием и выводом оставались пропущенные шаги.

Эти 38 объяснений дополнены оригинальными разделами Kairon:

- механизм до первого действия: кто принимает запрос, какие данные читает
  программа, что означают переменная и поле;
- конкретный разбор собственных файлов, идентификаторов и событий;
- связь наблюдения с выводом и следующим вопросом;
- независимая проверка, пример отчёта или задача на перенос понимания;
- предел результата: тип не определяет вред, совпадение строки не доказывает
  запуск, HTTP-статус отличается от ошибки соединения.

Названия этих уроков стали предметнее, без уменьшительных обозначений и
«открытых дверей» вместо портов. Сохранены взрослый простой русский, обращения
на «ты», конкретные шаги и существующие рабочие примеры. Остальные 68 подробных
уроков не переписывались ради увеличения объёма.

На `/study-plan` добавлено раскрываемое руководство по прохождению занятия.
Общий блок помощи с папкой дополнен различием команды, вывода, кода Python и
примера отчёта. Это доступно во всех уроках, использующих скачиваемые наборы.

## Сохранённые договорённости

ID, порядок дней, время, вопросы, ответы, варианты выбора, подсказки, разборы
после ответа, контрольные списки и практика сохранены. Из ресурсов добавлена
только справка ClamAV по кодам завершения. Все ZIP и исходные файлы упражнений
остались прежними. Дополнительные опыты Python выполняются в отдельно
сохранённых копиях `hello_practice.py` и `cipher_practice.py`.

## Основания проверки

Примеры сверены с `public/labs/kairon-kali-lab`, `kairon-diagnostics`,
`kairon-analysis`, `kairon-projects` и исходным кодом их программ.
Новые объяснения написаны для этих данных; сторонние учебники не копировались.

Для технических уточнений использованы первичные справки:

- [Python: строки, переменные и вывод](https://docs.python.org/3/tutorial/introduction.html);
- [Python: hashlib](https://docs.python.org/3/library/hashlib.html),
  [Base64](https://docs.python.org/3/library/base64.html);
- [Nmap: смысл состояний портов](https://nmap.org/book/man-port-scanning-basics.html);
- [Wireshark: назначение и устройство анализатора](https://www.wireshark.org/docs/wsug_html_chunked/ChapterIntroduction.html);
- [ClamAV: проверка файлов](https://docs.clamav.net/manual/Usage/Scanning.html),
  [коды завершения clamscan](https://github.com/Cisco-Talos/clamav/blob/main/docs/man/clamscan.1.in).

Функциональная проверка использует существующие тесты уроков, локального
прогресса и учебных наборов. В браузерной проверке дополнительно открывается
руководство с клавиатуры и раздел опыта Python на мобильной ширине; сохраняются
изображения раскрытого объяснения. Объём текста сам по себе не считается
доказательством качества объяснения.
