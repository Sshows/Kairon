# Архитектура Kairon 0.5

## Текущий продукт

Next.js на Vercel отдаёт 40 русских пошаговых гайдов в трёх путях, каталог 69 проектов, официальные ссылки, три учебных ZIP и API самопроверки. Kali работает на компьютере ученика. Браузерного shell, удалённого терминала и серверных Kali-сессий нет.

Гость может читать любой урок, скачать материалы и проверить ответ. Для гостя API возвращает результат и разбор без записи в БД и без XP. Каждый путь можно начать отдельно. Для вошедшего ученика нужны согласие с правилами и последовательное прохождение внутри выбранного пути; зачёт хранится в PostgreSQL.

## Данные

User, AuditLog, LoginAttempt и LessonProgress используют существующие миграции. Эта смена курса не требует миграции БД и не удаляет накопленные результаты. В текущем счётчике учитываются только ID нового курса. Старые награды остаются в общем XP.

Auth.js Credentials, закрытая выдача аккаунтов, bcrypt, версия сессии и немедленная блокировка. Prisma с ограниченной ролью kairon_runtime, FORCE RLS, transaction-local контекст из проверенной сессии. DIRECT_URL используется только доверенным CLI, не Vercel runtime.

## Поток проверки

Ученик отвечает → POST /api/learning/[lessonId] → проверка Origin, размера и строгой схемы → серверное сравнение ответа → гостевой результат либо транзакция LessonProgress → разбор и UI.

API больше не принимает mode, commands или флаг успеха. Ответы и разбор до решения отсутствуют в publicLesson. Это самопроверка понимания/наблюдения, а не доказательство действий в внешней Kali. Галочки чек-листа никуда не отправляются.

В аккаунте pg_advisory_xact_lock по пользователю защищает порядок и однократную награду от конкуренции. До трёх подсказок по 10 XP, максимум 20 проверок за минуту на урок. Повторный ответ на выполненный урок не добавляет XP.

## Контент и учебные программы

- content/lessons/kali.json — 20 текстов Kali; company.json — 12 дел безопасности компании; projects.json — 8 уроков создания маленьких инструментов. Все 32 прежних объяснения переписаны проще без смены ID, ответов и XP.
- content/project-catalog.json — полный список 69 строк проверенного README Cybersecurity-Projects: 43 папки с исходниками и 26 идей, оригинальные русские планы и pinned ссылки. Серверные страницы /projects/[id]; в клиент поиска передаются только поля карточек.
- src/lib/lessons.ts — серверный контент и DTO без ответов.
- src/components/lesson-workspace.tsx — гайд, самопроверка, ссылки и переходы.
- public/labs/kairon-kali-lab — авторские текстовые улики и две программы Python.
- scripts/build-kali-kit.py — воспроизводимый ZIP, SHA256 и искусственный PCAP.
- tests/kali_kit_test.py — реальный запуск локального учебного сайта/процесса в временной копии, проверка ZIP и PCAP.
- public/labs/kairon-projects — семь собственных offline-программ Python и вымышленные данные, всего 15 файлов. Программы только читают образцы и печатают результат; не требуют сторонних пакетов.
- scripts/build-projects-kit.py — воспроизводимый ZIP и SHA256; tests/projects_kit_test.py — запуск всех примеров, сверка выводов, отрицательный случай HTTP-разбора и неизменность исходных файлов.

serve.py слушает только 127.0.0.1:8000 и отдаёт две встроенные страницы. Доступа к файлам через HTTP нет. lab-worker.py только ждёт остановки. Ни одна из этих программ не запускается приложением Vercel.

## Оставшаяся работа

Полный редактор Path/Module/Lesson в админке, другие направления, AI-наставник, сертификаты и пробная группа. Документы lab-host-plan.md и services/lab-orchestrator — архив предыдущей идеи удалённых лабораторий; они не описывают обязательную инфраструктуру текущего курса.

Новый путь использует public/labs/kairon-company-lab: только 27 статических файлов. src/lib/learning-paths.ts задаёт независимые программы и метаданные наборов. getCourseLessons и isUnlocked выбирают предыдущие уроки только своего пути. Миграций для второго пути нет. Аудит Telegram содержит только метаданные, темы, ссылки и SHA256, без копии исходных сообщений.
