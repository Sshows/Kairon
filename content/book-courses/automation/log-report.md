## Перед началом: Задача: перестать пересчитывать журнал руками

Представь, что ты отвечаешь за небольшой учебный сайт. Утром тебе передали журнал входов: время, имя аккаунта и результат попытки. Вчера было десять строк, сегодня — несколько тысяч. Нужно узнать, у каких аккаунтов встречались отказы, и сохранить результат так, чтобы коллега мог его проверить. Программа выполнит повторяющуюся работу, а вывод о причинах останется за человеком.

Это похоже на работу с банковской выпиской. Калькулятор умеет сложить расходы, но не знает, была ли покупка полезной и кто держал карту. Наш скрипт тоже считает события по правилам. Два отказа могут возникнуть из-за опечаток, старого пароля в приложении или подбора. Без других данных выбирать одну причину нельзя.

После занятия у тебя будут исходный журнал, собственный анализатор и отдельный JSON-отчёт. Мы начнём с трёх строк: маленький набор позволяет сначала проверить алгоритм вручную. Автоматизировать непонятное действие опасно ещё и потому, что ошибка повторяется очень быстро.

## Сделай сейчас: Подготовь папку и пойми, куда писать код

Открой терминал **внутри Kali Linux**. Команды ниже вводятся после приглашения терминала, без символов `$` и надписи `kali@...`.

```bash
mkdir -p ~/kairon-reading/automation
cd ~/kairon-reading/automation
pwd
python3 --version
```

`mkdir` создаёт папку. `-p` разрешает создать и промежуточную папку `kairon-reading`, если её ещё нет. `~` означает домашнюю папку твоего пользователя; имя компьютера вместо него вводить не нужно. `cd` меняет текущую папку терминала. `pwd` покажет реальный путь, например `/home/kali/kairon-reading/automation`. У тебя имя пользователя может отличаться — это нормально. Последняя команда показывает установленную версию Python 3.

Открой редактор Mousepad из меню Kali. Создай файл `events.jsonl` в этой папке. Расширение `.jsonl` означает, что **каждая строка — самостоятельный JSON-объект**. Вставь три строки и сохрани:

```json
{"time":"2026-01-10T10:00:00Z","user":"anna","result":"denied"}
{"time":"2026-01-10T10:01:00Z","user":"anna","result":"denied"}
{"time":"2026-01-10T10:02:00Z","user":"boris","result":"allowed"}
```

Это вымышленные данные. `Z` обозначает время UTC. `user` — условное имя аккаунта, `result` — результат входа. Кавычки должны быть обычными двойными, как в блоке. В JSON нельзя заменить их типографскими «ёлочками». Не добавляй запятые между строками: это не один большой массив.

## Сделай сейчас: Напиши программу и разбери её устройство

В Mousepad создай рядом файл `report.py`. В него вставляется **код Python**, а не команда запуска:

```python
import json
from collections import Counter
from pathlib import Path

source = Path("events.jsonl")
denied = Counter()
total = 0

with source.open(encoding="utf-8") as stream:
    for number, line in enumerate(stream, start=1):
        if not line.strip():
            continue
        try:
            event = json.loads(line)
        except json.JSONDecodeError:
            raise SystemExit(f"Строка {number}: некорректный JSON")
        if not isinstance(event, dict):
            raise SystemExit(f"Строка {number}: нужен объект")
        if not isinstance(event.get("user"), str):
            raise SystemExit(f"Строка {number}: нет имени аккаунта")
        if event.get("result") not in {"allowed", "denied"}:
            raise SystemExit(f"Строка {number}: неизвестный результат")
        total += 1
        if event["result"] == "denied":
            denied[event["user"]] += 1

report = {"events": total, "denied_by_user": dict(denied)}
Path("report.json").write_text(
    json.dumps(report, ensure_ascii=False, indent=2),
    encoding="utf-8",
)
print(json.dumps(report, ensure_ascii=False, indent=2))
```

`import` подключает готовые части стандартной библиотеки Python. `json` разбирает формат данных; `Counter` хранит счётчики; `Path` представляет путь к файлу. Устанавливать эти модули через `pip` не нужно.

`source` — переменная, содержащая путь. Мы передаём относительное имя `events.jsonl`: поиск начнётся **в текущей папке терминала**, а не обязательно там, где лежит скрипт. Поэтому в подготовке был `cd`. Блок `with` открывает файл и закроет его даже при ошибке. `encoding` явно задаёт кодировку.

Цикл `for` обрабатывает строки по очереди. `enumerate(..., start=1)` добавляет удобный человеку номер строки. Пустая строка пропускается через `continue`. `json.loads` превращает текст в объект Python; `try/except` превращает непонятный сбой в сообщение с номером повреждённой строки.

Дальше проверяется **форма** данных. Корректный JSON может оказаться числом или списком, поэтому одного успешного разбора недостаточно. `isinstance(event, dict)` требует объект, `event.get` проверяет нужные поля. Только после проверок растёт `total`. Если результат равен `denied`, увеличивается счётчик конкретного аккаунта. Отступы показывают, какие действия относятся к условию: они являются частью синтаксиса Python.

В конце обычный словарь превращается обратно в JSON. `indent=2` делает отступы для чтения, `ensure_ascii=False` сохраняет русские буквы. `write_text` записывает **новый отчёт**; исходный журнал программа не переписывает. Повторный запуск заменяет прежний `report.json`, поэтому собственные комментарии лучше хранить отдельно.

## Сделай сейчас: Запусти и сверь результат

Сохрани файл, вернись в терминал и выполни:

```bash
python3 report.py
cat report.json
```

Первая команда запускает интерпретатор Python 3 и передаёт ему файл программы. Вторая просто читает получившийся отчёт. Обе должны показать:

```json
{
  "events": 3,
  "denied_by_user": {
    "anna": 2
  }
}
```

Проверь руками: всего три непустые строки, две из них содержат отказ для `anna`. Теперь добавь четвёртую корректную строку с отказом для `boris` и повтори запуск. Ожидается `events: 4`, у `anna` останется 2, появится `boris: 1`. Это проверка алгоритма на изменённых входных данных, а не запоминание заранее показанного ответа.

## Сделай сейчас: Проверь ошибки и сформулируй вывод

В копии журнала удали одну кавычку. Программа должна остановиться с номером строки. Это полезнее, чем молча пропустить событие и выдать неполный отчёт как полный. Верни кавычку и замени `denied` на `unknown`: получишь отдельное сообщение о неизвестном результате. Так проверяются два разных слоя — синтаксис и смысл полей.

`FileNotFoundError` означает, что файл не найден по выбранному пути: сверь `pwd` и `ls`. `IndentationError` указывает на отступы Python; не смешивай табуляцию с пробелами. Если Mousepad сохранил `report.py.txt`, включи отображение расширений и исправь имя. Сообщение `command not found: import` обычно означает, что код Python был введён прямо в оболочку вместо файла.

Законченный результат занятия — не только работающий код. Запиши рядом: «В четырёх учебных событиях обнаружены три отказа, сгруппированные по аккаунтам. Причина отказов и факт успешного постороннего входа не установлены». Для настоящего большого журнала дальше понадобятся ограничения размера, формат времени, обработка дубликатов и тесты. Начинать следует с проверяемого маленького правила, которое ты уже умеешь объяснить.
