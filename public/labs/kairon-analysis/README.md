# Проверяем файл без запуска: набор Kairon

Все сведения, события и адреса вымышлены. Это оригинальные упражнения Kairon, а не файлы из Malware Bible.
В наборе только обычный текст UTF-8: CSV, TXT и Markdown. Нет PE/ELF-программ, скриптов, вредоносных файлов, макросов, архивов с паролем и автоматического запуска.

Распакуй kairon-analysis в домашнюю папку Kali. Читать можно текстовым редактором или командой cat.
READY.txt содержит ANALYSIS-READY-28. Начни с case-notes.txt.
samples/invoice.pdf.txt — обычный текст, несмотря на .pdf в середине имени. Открывай его через текстовый редактор.
format-cards.csv содержит запись шестнадцатеричных знаков словами, а не реальные заголовки исполняемых файлов.
strings-review.txt и scan-observations.csv — заранее подготовленные демонстрационные наблюдения. Они не являются результатом запуска YARA или антивируса в этой сессии.
event-timeline.csv — сокращённая искусственная последовательность событий, не экспорт настоящей Windows.

Сами адреса *.example.invalid никуда не открывай: они обозначают учебные строки. Для задания достаточно чтения файлов.
В reports/template.md запиши факты, неизвестное и следующий согласованный шаг. Сайт документ не загружает и не оценивает.
Имя файла, одна строка, совпадение простого правила и даже формат файла сами по себе не доказывают заражение.
Для настоящего подозрительного вложения используй порядок своей организации и подготовленную команду, а не копируй шаги учебного чтения на неизвестный файл.

Источник тем: Perkins-Fund/Malware-Bible и paulveillard/cybersecurity. Объяснения и все файлы этого набора написаны заново для Kairon.
