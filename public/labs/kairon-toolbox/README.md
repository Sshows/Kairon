# Kairon: инструменты Kali на своём стенде

Все программы и данные этого набора написаны для Kairon. Учебный сервис работает только на 127.0.0.1:8765 внутри системы, где его запустили. Никаких внешних целей, реальных аккаунтов и вредоносных программ в наборе нет. Нужны обычные права пользователя; sudo применяется только при установке отсутствующих пакетов через apt.

## Начало

Распакуй папку kairon-toolbox в домашнюю папку своей Kali. В терминале:

```bash
cd ~/kairon-toolbox
cat READY.txt
mkdir -p work
python3 service.py
```

Ожидаемый код: TOOLKIT-READY-28. Последняя команда держит терминал занятым: здесь работает сервер. Открой вторую вкладку терминала, снова перейди в ~/kairon-toolbox и выполняй проверки из уроков. Чтобы остановить сервер, вернись в первую вкладку и нажми Ctrl+C. Адрес 127.0.0.1 в Windows относится к Windows, а не к Kali.

## Какие инструменты нужны

Устанавливай только то, чего нет и что нужно текущему уроку. Nmap проверяет порт, Netcat переносит текст, Hydra пробует четыре учебных пароля к своему HTTP Basic, Hashcat сравнивает четыре слова с собственным SHA-256. OpenSSL нужен для хешей, шифрования, подписи, сертификата и HMAC. Python 3 запускает наш сервис. На Kali с nc.traditional используй пакет netcat-openbsd и команду nc.openbsd: у разных Netcat различаются флаги.

Учебный логин: trainee. Учебный пароль: kairon28. Он намеренно находится в небольшом словаре, чтобы показать механизм на короткой задаче; он не подходит для настоящего аккаунта. HTTP Basic сам по себе не шифрует пароль. Этот пример остаётся на loopback; рабочему входу нужны соответствующие защита и политика доступа.

Hashcat в виртуальной машине может не найти вычислительное устройство. В уроке разобраны установка CPU OpenCL через pocl-opencl-icd, проверка hashcat -I и корректная остановка при нехватке ресурсов. Обход ошибок через --force и большие тесты производительности не нужны.

## Файлы

- service.py и web/index.html: свой маленький HTTP-сервис с /, /health, /private и ответом 404 для других путей.
- data/order.txt и order-changed.txt: два разных заказа для сравнения хешей.
- data/message.txt и message-changed.txt: исходный и изменённый учебный текст.
- data/wordlist.txt: ровно четыре вымышленных пароля; demo.sha256 — SHA-256 слова kairon28 без перевода строки.
- data/netcat-note.txt: текст для передачи через свой локальный порт.
- data/hmac-message.txt и hmac-message-changed.txt: два сообщения для проверки HMAC.
- reference/tool-notes.txt: условия и ограничения выводов; report-options.csv: три варианта заключения.
- reports/template.md: бланк для своей копии отчёта. Все результаты сохраняй в work; исходные файлы оставь для повторения.
