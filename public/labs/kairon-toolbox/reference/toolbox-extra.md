# Дополнительные инструменты: файлы и локальный сервис

Эти данные созданы для Kairon. invoice.pdf.txt и reference-note.txt — обычные ASCII-тексты; общий маркер KAIRON-REVIEW-28 нужен для сопоставления strings и YARA. Наличие маркера не означает вредоносность.

metadata.png — собственное изображение 1×1 с описанием KAIRON-META-28 и Software=Kairon. Оно не является фотографией и не содержит GPS. Изменения выполняй только на копии в work.

http-response.json — сохранённый вымышленный JSON для jq, не ответ скрытого API. В нём учебный статус ready и два заказа: 3 и 5 коробок.

paths.txt — четыре пути для своего service.py: health, private, missing и docs. Этот же сервис слушает только 127.0.0.1:8765 в твоей Kali; health возвращает200, private без учебного входа401, отсутствующие пути404. Gobuster сравнивает только этот список; полной карты приложения он не строит.

traffic/local-http.pcap содержит собственную синтетическую запись TCP/HTTP GET /health на8765 и ответ200. Это данные для чтения tcpdump/TShark, а не перехваченная чужая сеть. dns_server.py — собственный DNS-слушатель127.0.0.1:1053 для training.test A. Подготовка описана в уроках.

Все результаты складывай в work. Старые учебные документы и сервис сохранены; переустанавливать Kali, менять домашнюю сеть или регистрироваться на платной платформе не нужно.
