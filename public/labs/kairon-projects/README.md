# Свои инструменты: учебный набор Kairon

Это собственные небольшие примеры Kairon. Они не являются копией программ CarterPerez-dev.
Python 3, только стандартная библиотека. Запускай команды из папки kairon-projects.
Программы читают только файлы samples рядом с собой и выводят результат на экран.
Сети, скрытого наблюдения, установки пакетов, удаления и изменения файлов нет.
В папке нет настоящих паролей, вирусов и личных данных.

python3 hello.py
python3 hash_lab.py
python3 base64_lab.py
python3 cipher_lab.py
python3 headers_lab.py
python3 log_lab.py
python3 integrity_lab.py

Учебный шифр Цезаря и Base64 не подходят для хранения секретов.
Правило длины хеша лишь подсказывает возможный формат; это не доказательство алгоритма.
Отсутствующий HTTP-заголовок не доказывает взлом сайта.
Хеш обнаруживает изменение, но сам по себе не называет автора и не доказывает вирус.
