Это вымышленные сохранённые случаи. Не открывай адреса: соединения не создаются.

case-a
URL: http://shop.example/login
Соединение: HTTP без TLS
Обмен: GET /login -> HTTP/1.1 200 OK

case-b
URL: https://shop-support.example/login
Соединение: HTTPS, проверка сертификата успешна для shop-support.example
Проверенный рабочий адрес компании: shop.example
Наблюдение: соединение зашифровано, но домен отличается от рабочего адреса.

case-c
URL: https://shop.example/orders
Соединение: HTTPS, проверка сертификата успешна для shop.example
Обмен: GET /orders -> HTTP/1.1 200 OK
Наблюдение: имя совпадает с ожидаемым; права к отдельным заказам ещё нужно проверять.
