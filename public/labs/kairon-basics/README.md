# Основы безопасности: учебные случаи Kairon

Все ситуации, адреса, пользователи и данные вымышлены. Это собственный набор Kairon, а не копия материалов авторов планов обучения.
В наборе только текстовые файлы. Нет программ, сканирования, настоящих ключей и запуска облачных сервисов.

Распакуй папку kairon-basics в домашнюю папку Kali. Открой READY.txt, затем файл из урока.
В терминале можно читать: cd ~/kairon-basics и cat имя-файла. Команды выполняй по одной строке.
Все файлы также можно открыть текстовым редактором. Таблицы CSV разделены запятыми; первая строка называет столбцы.

cia-cases.csv — три разных последствия для данных.
risk-register.csv — приоритет по ситуации компании, а не только по числу.
addresses.csv — локальный, частный и адрес для документации.
dns-records.txt — сохранённые учебные записи имён.
services.csv — адрес и порт разных учебных служб.
http-cases.txt — соединение с сайтом и доверие к самому сайту.
login-methods.csv — разные способы проверки входа.
access-rules.csv — кому разрешено читать какой заказ.
data-flow.txt — путь заказа через границу доверия.
release-plan.csv — варианты работы с обновлением программы.
cloud-responsibility.csv — ответственность за разные настройки.
ai-case.txt — недоверенный текст и разрешённые действия помощника.

Сайт проверяет короткий ответ. Он не наблюдает за компьютером и не оценивает записанный тобой отчёт.
Учебные темы подсказаны jassics/security-study-plan и Hamed233/Cybersecurity-Mastery-Roadmap.
Ссылки и первичные источники находятся в уроках. Код и изображения этих репозиториев сюда не включены.
